# Vectolith blueprint identity

The blueprint SVG is a repository-ready, scalable presentation of the Vectolith geometric emblem.

- **SVG source:** `assets/branding/vectolith-blueprint.svg`
- **Existing emblem:** `assets/vectolith-icon.svg`

## Usage

Use the existing emblem for small-size marks, icons and compact UI placements. Use the blueprint artwork for repository documentation, technical presentations and wide-format visual context. The SVG is vector-based and can be resized without raster scaling.

## Identity integrity

The blueprint is a presentation variant of the geometric mark, not a replacement for the original icon. Keep the original icon source unchanged. The poster's grid, dimension annotations and alternate studies are illustrative layout elements, not engineering dimensions or authoritative geometry specifications.

## Rendering and accessibility

The artwork includes a title and description for SVG-capable viewers. In Markdown, use an informative alternative text description. If the image is used as decorative content in a UI, provide an empty alt attribute and ensure surrounding content conveys relevant information.
