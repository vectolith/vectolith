# Vectolith icons

A reusable 36-icon outline set. Each symbol uses a 24×24 viewBox, 2-unit stroke, round caps/joins. Reference color: `#0033CC`. Use the sprite with SVG `<use>` references or copy individual symbol markup into a standalone SVG.

## Example
```svg
<svg viewBox="0 0 24 24" stroke="#0033CC" fill="none" stroke-width="2" stroke-linecap="round" stroke-linejoin="round">
  <use href="icons.svg#home" />
</svg>
```

The sprite is accompanied by a visual sheet and standalone favicon asset.
