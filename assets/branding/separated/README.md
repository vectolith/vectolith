# Vectolith separated brand assets

This folder contains identity components individually, for reuse in documentation, product UI, presentations and brand materials.

| Asset | Purpose |
|---|---|
| `mark.svg` | Standalone geometric symbol |
| `wordmark.svg` | Typography-only VECTOLITH wordmark |
| `logo-horizontal.svg` | Symbol + wordmark side by side |
| `logo-stacked.svg` | Symbol above wordmark |
| `construction.svg` | Geometry and symmetry study |
| `colors.svg` | Brand swatches |
| `clear-space.svg` | Spacing guidance illustration |

## Typography
- Primary direction: geometric sans-serif.
- Preferred family: Space Grotesk.
- Fallbacks: Manrope, Avenir Next, Segoe UI, sans-serif.
- Wordmark: uppercase, semibold, optically tracked.

SVG wordmark uses a font stack rather than embedded font outlines. Appearance may vary if the preferred font is unavailable. For final production use, convert the text to outlines in a vector editor and preserve the editable source separately.

## Color references
- Vectolith Blue: `#0033CC`
- White: `#FFFFFF`

These are current reference colors, not a complete color-management specification.

Construction and clear-space diagrams are illustrative, not verified mechanical dimensions. The comprehensive blueprint poster remains available as the visual reference.
